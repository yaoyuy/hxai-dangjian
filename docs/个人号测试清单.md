## 2. 个人号测不了的（别浪费时间，也别谎报）

| 功能 | 为什么不行 | 系统现在的行为 |
|---|---|---|
| 微信网页授权（拿 openid） | 个人订阅号无 `snsapi_base` / `snsapi_userinfo` 权限，调用返回 `api unauthorized` | 用本地测试账号，页面明确标"非微信身份"，`openid` 留空 |
| 自定义菜单 API 自动推送 | 个人号调 `menu/create` 返回 `48001 api unauthorized` | `/api/wechat/menu/push` 会把 48001 原样返回，**不假装成功** |
| 模板消息 / 订阅消息 | 无权限 | 未实现，只留说明 |
| 客服消息 | 无权限 | 未实现 |
| 微信支付 / JS-SDK 签名 | 无权限，项目也不需要 | 未实现 |
| 服务器 URL 接入微信回调 | 微信要求公网 HTTPS 域名，`127.0.0.1` 和局域网 IP 都不行 | `/wechat` 代码已写好，**可在本地用自算签名验证验签逻辑**（实测：正确签名返回 echostr，错误签名 403，POST 文本消息能返回被动回复 XML），但**接不上真微信** |
| 真机上的微信身份免密登录 | 依赖上面第一条 | 现在只能输账号密码 |
| 小程序 `wx.login` 真实换 openid | 需要小程序 AppID + **已备案 HTTPS 域名**填进小程序服务器域名；本地没有备案域名，微信不会放行 | 接口（`jscode2session`）与**小程序前端代码都已写好**（`miniprogram/`），本地只能用 `dev_openid` 或测试账号联调，页面如实标注"非真实微信授权" |
| 手机微信里点菜单直接进系统 | 未认证个人号不能用「跳转网页」（实测报"链接内容不属于当前公众号"） | 现在的菜单是"发送消息 → 文字带网址"，要点两次 |

### 这些"等学校号"的具体含义

| 要等的 | 学校要提供 | 到时候改哪里 |
|---|---|---|
| 网页授权 | 已认证公众号（服务号或认证订阅号）的 AppID + AppSecret | `.env` 的 `WECHAT_APPID/APPSECRET` + `LOGIN_MODE=wechat`，并实现 OAuth 回调 |
| 菜单推送 | 同上 | `backend/wechat.py` 的 `create_menu()` 已经写好，换个 AppID 就能调 |
| 模板消息 | 已认证 + 模板消息权限（服务号） | 新增一个通知模块 |
| 服务器回调 | 公网 HTTPS 域名 + 已备案 | `.env` 的 `PUBLIC_BASE_URL` + 公众号后台填 URL/Token |
