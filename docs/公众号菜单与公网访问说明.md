# 公众号菜单与公网访问说明（第一阶段 · 个人订阅号 HXAI云）

> 这份文档记录“菜单是怎么挂上去的、为什么只能这么做、掉线了怎么办”。

## 一、结论先说

| 事项 | 状态 |
|---|---|
| 自定义菜单（3 主菜单 + 8 子菜单） | ✅ 已在微信公众平台后台建好并**发布成功** |
| 菜单点击后的行为 | 发一条**文字消息**，文字里带系统网址，点网址打开系统 |
| 为什么不是“点菜单直接打开网页” | ❌ 未认证个人订阅号不能用「跳转网页」类型，保存时报「链接内容不属于当前公众号」 |
| 菜单里写的是什么网址 | **校园网内网地址** `http://192.168.x.x:5000/...`（手机连校园 WiFi 才能打开；校园网是 DHCP，IP 变了要按第五节重新发布菜单） |
| 为什么不用公网隧道 | 免费匿名隧道（localhost.run）约 **20 分钟**换一次域名，而菜单发布最长 **60 分钟**才生效，追不上 |
| 手机在外网（流量 / 家里 WiFi）能打开吗 | ⚠️ 现在不能。要外网可访问，需要固定域名（邮箱注册 localhost.run）或等第二阶段学校服务器 |
| 需要本机一直开着吗 | ✅ 需要。电脑关机 / 断网，菜单里的链接就打不开了 |

## 二、菜单结构

```
党建学习 ── 学习专栏   → /study
        ├─ 云党课     → /study?category=cloud
        └─ 党史学习   → /study?category=history

组织生活 ── 三会一课   → /meetings
        ├─ 活动报名   → /activities
        └─ 电子台账   → /ledger

支部风采 ── 党建风采   → /gallery
        └─ 数据看板   → /dashboard
```

每个子菜单的「消息类型」= **发送消息**，「菜单内容」= **文字**，文字内容形如：

```
打开智慧党建 · 学习专栏 http://192.168.x.x:5000/study
```

> 8 个子菜单内容里的地址**统一是校园网内网地址** `http://192.168.x.x:5000`，
> 不是隧道域名——原因是隧道域名活不过菜单的生效时间（见第五节）。
> 如果以后拿到固定域名（学校域名或注册后的固定隧道域名），把这 8 条内容整体换掉再发布一次即可。
>
> ⚠️ 校园网由 DHCP 分配地址，**换网络或过一段时间后这个 IP 可能会变**（实测就变过一次：
> `10.103.21.102` → `192.168.x.x`）。查当前 IP 的办法：双击根目录的 `启动智慧党建.bat` 会打印出来，
> 或者命令行 `ipconfig`。IP 变了就按本节 + 第五节把 8 条菜单内容重新发布一次。

### 为什么不能用「跳转网页」

微信的规则是：自定义菜单里「跳转网页」的链接，内容必须属于当前公众号
（要么是 mp.weixin.qq.com 上本号已发表的文章，要么是已配置**网页授权域名/业务域名**的自有域名）。

- 配置网页授权域名 / 业务域名需要**已认证**的公众号；
- 个人未认证订阅号没有这个权限，也调不了自定义菜单 API（返回 48001）；
- 所以任何外部网址填进去，点保存都会报 **「发布失败，链接内容不属于当前公众号」**。

**这不是代码问题，也不是隧道问题，是账号权限问题。** 换成学校已认证的公众号后，
就可以直接用「跳转网页」把菜单指向系统页面（第二阶段的 `/api/wechat/menu/push` 已经写好备用）。

### 想「点一下直接进系统」→ 只能做小程序

菜单编辑页的「消息类型」里确实有 **「跳转小程序」** 这一项，也点得动，但：

- 点「选择小程序」只给两个选项：**复制小程序链接** / **选择已关联的小程序**；
- 选后者弹窗提示 **「暂无关联的小程序，请在“小程序-小程序管理”内进行关联」**；
- 进公众平台的「小程序」入口（<https://mp.weixin.qq.com/cgi-bin/wx>）拿到的是**注册引导页**
  （「前往注册 / 找服务商帮我做」）——**说明 HXAI云 这个号一个小程序都没有。**

所以顺序是：**先注册一个小程序 → 关联到公众号 → 菜单才能选「跳转小程序」**。
本项目的小程序前端代码已经写好（`miniprogram/`，原生 WXML/WXSS/JS，后端一行不用改），
只差一个 AppID。完整流程、材料、时间与风险见 [小程序开发与发布.md](小程序开发与发布.md)。

## 三、公网访问是怎么打通的（备用方案，当前菜单没用它）

> 这一段是"万一要走外网"的备用通道。**当前菜单里写的是校园网内网地址**，
> 原因见第五节（隧道域名活不过菜单生效时间）。

本机在运营商大内网里（内网 10.103.21.102，出口 183.221.157.214），没法做端口映射，
所以用 **SSH 反向隧道**把本机 5000 端口暴露到公网：

```bash
# 在项目根目录执行
ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null \
    -o ServerAliveInterval=20 -o ServerAliveCountMax=3 \
    -R 80:127.0.0.1:5000 nokey@localhost.run
```

服务端会分配一个临时域名（写成 `https://xxxxxxxx.lhr.life`），本机 Flask 的 5000 端口
就等于这个公网地址。当前域名记录在项目根目录的 `.tunnel_url` 文件里。

> Cloudflare 免费隧道在这个网络环境下**不可用**（api.trycloudflare.com 被墙，连接超时），
> 已经试过并放弃。serveo.net 免费版要注册 SSH key 才能固定域名，且随机域名很长，
> 也没有采用。

## 四、开机自动启动 + 保活脚本

### 开机自动启动（已配置好）

已经在本机放好了两个东西，**登录 Windows 后会自动把服务跑起来**，不用手动点：

| 位置 | 作用 |
|---|---|
| 启动文件夹的快捷方式 `智慧党建.lnk`（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`） | 开机登录时静默启动 |
| `tools\start_server.vbs` | 真正干活：设置 `APP_HOST=0.0.0.0`、`APP_PORT=5000`，隐藏窗口启动 `run.py` |

想取消开机自启：删掉启动文件夹里的 `智慧党建.lnk` 即可（或运行
`Remove-Item ([Environment]::GetFolderPath('Startup') + '\智慧党建.lnk')`）。
想手动启动：双击根目录的 `启动智慧党建.bat`。已实测：杀掉全部 Flask 进程后运行 `start_server.vbs`，
`127.0.0.1:5000` 和 `192.168.x.x:5000` 都恢复 200。

### 保活脚本（可选）

`tools/keep_online.sh` 会一直守着两件事：

1. Flask（5000 端口）没响应就自动拉起（实测杀掉进程后 **6 秒**就恢复）；
2. 隧道断了就自动重连，并把新域名写进 `.tunnel_url`。

启动方式：

```bash
cd /d/GZH/hxai_dangjian
bash tools/keep_online.sh &        # 后台常驻
bash tools/keep_online.sh --once   # 只检查一次，不进循环
```

设计上的两个细节（都是为了不瞎折腾）：

- **连续 3 次探测失败**（约 3 分钟）才判定隧道掉了，避免一次网络抖动就把域名换掉；
- 重连时**只结束脚本自己拉起的那个 ssh 进程**（记在 `.tunnel.pid`），
  不会去杀你其它的 SSH 会话（比如连学校/云服务器的）。

日志：`keep_online.log`（保活动作）、`tunnel.log`（隧道原始输出）、`server.log`（Flask 输出）。
域名变了会额外写一行 `!! 域名已变化：公众号菜单里的链接需要重新发布 !!`。

## 五、隧道域名变了怎么办（重要）

### 问题比"域名会变"更严重

实测数据（`keep_online.log`）：

| 隧道建立 | 判定失效 | 存活 |
|---|---|---|
| 00:32:31 | 00:53:05 | 约 20.5 分钟 |
| 01:01:28 | 01:19:03 | 约 17.6 分钟 |

**免费匿名隧道大约 20 分钟就断一次，重连后域名会变。** 而公众号菜单发布一次
**最长 60 分钟**才生效。两个数字一对上就明白了：

> 域名还没等到菜单生效就已经换掉了 → **在拿到固定域名之前，反复重发菜单是白费力气。**

所以**菜单里最终没有写隧道域名**，而是改成了校园网内网地址 `http://192.168.x.x:5000/`：
它不需要注册、点开就能用，代价是**手机必须连校园 WiFi**，而且校园网 DHCP 换地址后要重发一次菜单。
如果你要求"手机用流量也能打开"，那就得先解决"域名固定"这件事，办法见下。

### 让域名固定的唯一免费办法

localhost.run 官方 FAQ 原文：

> "My tunnel name changes every time I connect — Free tunnels change domain names after a few hours.
> **To keep your domain name between connections make sure you have an SSH key and that you are not using the `nokey` username.**"

也就是说：**注册账号 + 登记本机 SSH 公钥 + 连接时不用 `nokey` 用户名**，域名就能在重连之间保持不变。

注册入口：https://admin.localhost.run/ ，两种登录方式：

| 方式 | 现状 |
|---|---|
| login with **email**（邮箱收验证码） | ✅ 可用，**推荐** |
| login with **google** | ❌ 打不开（accounts.google.com 在国内被墙，实测 DNS 解析失败） |

**这一步需要你本人的邮箱**（邮箱验证码我收不到），所以卡在这里等你。

### 其它方案都试过了，走不通

| 方案 | 为什么不采用 |
|---|---|
| Cloudflare 免费隧道 | api.trycloudflare.com 被墙，连接超时 |
| serveo.net 固定子域名 | 同样要先注册 SSH 公钥，且只能 Google/GitHub 登录 |
| localtunnel `--subdomain` | 免注册且子域名稳定，但免费版会插一个"Tunnel Password"中转页，微信里没法用 |
| bore.pub / ngrok / cpolar / natapp / 花生壳 | 要么随机端口，要么必须注册账号 |
| 本机公网 IPv6 直连 | 只有 Teredo 隧道地址（2001:0::/32），不能当服务器用 |
| 匿名隧道指定子域名 | localhost.run 不支持 |

### 怎么自己判断"域名有没有变"

浏览器打开健康检查地址，里面就有当前对外地址：

```
http://127.0.0.1:5000/healthz
```

返回里的 `public_base_url` 是**外网隧道地址**（备用通道，没写进菜单）。项目的 `.tunnel_url` 文件和它是同一个来源。
> **菜单里现在写的是校园网内网地址**，不是这个隧道地址——内网地址是用 `ipconfig` 查的
> （形如 `10.103.x.x`），会随校园网 DHCP 变化，见第二节的提醒。

> 代码里做了兜底：`.env` 的 `PUBLIC_BASE_URL` 没填时，会自动读 `.tunnel_url`。
> 所以本地测试时不需要手改 `.env`；第二阶段部署到学校服务器时，
> 在 `.env` 里填学校域名（`PUBLIC_BASE_URL=https://dangjian.xxx.edu.cn`）就会优先用它。

### 重新发布菜单的步骤（给以后用）

1. 打开 https://mp.weixin.qq.com/advanced/selfmenu （左侧「互动管理 → 自定义菜单」）。
2. 依次点每个主菜单下的每个子菜单，把「菜单内容」里的网址换成新域名。
   内容格式：`打开智慧党建 · 学习专栏 https://新域名/study`。
3. 改完点右下角 **保存并发布** → 弹窗点 **确认**，顶部出现「保存并发布成功」即可。
4. 8 个页面分别是：`/study`、`/study?category=cloud`、`/study?category=history`、
   `/meetings`、`/activities`、`/ledger`、`/gallery`、`/dashboard`。

要彻底稳定，还是得等第二阶段：把系统部署到学校服务器 + 学校域名 + HTTPS 证书，
那时候菜单直接写学校域名，永远不会变。

## 六、在手机上怎么验证

### 第一步：手机连校园 WiFi，直接用浏览器打开

1. 手机连**和电脑同一个校园 WiFi**。
2. 用手机浏览器打开 `http://192.168.x.x:5000/`（IP 可能变，用 `ipconfig` 查当前值）。
3. 能打开 → 说明网络通（电脑要开着机，Flask 在跑）。

> 打开前可以先在电脑上确认一次：`curl http://192.168.x.x:5000/healthz` 返回 `"ok": true`。
> 电脑上已经用这条地址实测过全部 8 个页面都是 200、静态资源正常；
> 服务端日志里也能看到手机（`10.103.30.113`）访问过 `/study`、`/article/5`、`/meetings`、`/gallery`，说明校园网内手机确实能打开。

### 第二步：等菜单生效后点菜单

1. 打开微信 → 找到公众号 **HXAI云**（订阅号在「订阅号消息」里）。
2. 菜单发布后**最长 60 分钟**生效（页面上的横幅写「预计60分钟后生效」）。
3. 点「党建学习 → 学习专栏」。
4. 公众号回一条文字消息，里面带网址 `http://192.168.x.x:5000/study`。
5. 点这条消息里的网址打开系统。

**如果点不动网址**：长按那条消息 → 复制 → 粘贴到微信聊天输入框再点，或者用手机浏览器打开。

### 打不开怎么办

| 现象 | 原因 | 办法 |
|---|---|---|
| 手机浏览器也打不开 `192.168.x.x:5000` | 手机不在校园网 / 校园 WiFi 做了终端隔离 / 电脑防火墙拦了 / **电脑 IP 变了** | 先用 `ipconfig` 确认电脑当前 IP；再考虑"外网能访问"的方案：邮箱注册 localhost.run 拿固定域名，或用自己的云服务器 |
| 手机浏览器能开、微信里点菜单没反应 | 菜单还没生效（最长 60 分钟） | 等一下再试 |
| 微信里提示"已停止访问该网页" | 微信对未备案/非常规地址的拦截 | 用手机浏览器打开；或等第二阶段学校已备案域名 |

### 备选：外网也能访问（需要固定域名）

隧道命令和保活脚本见第三、四节。**注意免费匿名隧道约 20 分钟换一次域名**，
只适合临时给手机看一眼，不适合写进菜单。

## 七、已知限制（如实说明）

1. 个人未认证订阅号**不能**做菜单「跳转网页」，只能发文字消息，多一次点击。
2. 菜单里的地址是**校园网内网地址**（当前 `192.168.x.x:5000`）：**手机必须连校园 WiFi**，
   用流量 / 在外网打不开；而且校园网 IP 会变（DHCP），变了要重新发布菜单。这是当前最大的限制。
3. 手机和电脑还必须在同一个局域网内能互通（校园 WiFi 若开了终端隔离，也会打不开）。
4. 本机必须开机、Flask 必须在跑，否则菜单点开也是打不开的。
5. 免费匿名隧道能解决"外网访问"，但**约 20 分钟换一次域名**，追不上菜单 60 分钟生效，
   所以没有写进菜单；要用它得先注册 localhost.run 拿固定域名（只需一个邮箱）。
6. 第二阶段换成学校服务器 + 学校已备案域名（HTTPS）后，上面这些限制全部消失：
   菜单可以直接用「跳转网页」指向学校域名。
7. 想让菜单**点一下直接进系统**，个人号的唯一现实路径是**小程序**
   （菜单「跳转小程序」可用，但必须先注册小程序并关联到本公众号；当前提示“暂无关联的小程序”）。
   小程序前端代码已写好（`miniprogram/`），流程见 [小程序开发与发布.md](小程序开发与发布.md)。
